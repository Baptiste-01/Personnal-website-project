## 🎯 Objective
Resolve critical gameplay and configuration issues across SpeedSmik / FlashGuess:
1. Allow players and administrators to individually select or exclude question categories during arena creation, persisting choices to the database and multiplayer rooms.
2. Eliminate duplicate categories and phantom cards in the arena lobby stemming from Neon database migration (slugs vs raw names divergence), perfectly aligning on the 14 real database categories.
3. Fix the question timer freeze occurring at ~11s–12s in online multiplayer mode and harden WebSocket connection lifecycles during the transition from the arena lobby (`/arena/:id`) to the game screen (`/play/:id`).

---

## 📋 Context & Root Cause Analysis

### 1. Category Selection in Arena Creation
- In `CreateArenaModal`, each category only showed difficulty pill toggles with static active styles, offering no controls to include or exclude a category.
- `handleCreateArena` omitted `categories: settings.categories` in the `POST /arenas` request payload, causing the database to fall back to a truncated default category set.
- Arena lobbies (`arenaWs.ts` and `Arena/index.tsx`) did not synchronize the database-stored arena categories when players joined without URL filter query params.

### 2. Post-Migration Duplicate Categories (Neon Database)
- During Excel/CSV import to Neon, `Question` stored raw sheet names (e.g., `Animaux & Dinosaures`, `Anime & Manga`, `Jeux Vidéo`, `Mythologie & Légende`) while `Category` stored simplified slugs (e.g., `animaux-dinosaures`, `anime-manga`, `jeux-vid-o`, `mythologie-l-gende`).
- `GET /questions/categories` merged both lists without canonical key normalization, leading to duplicates and empty phantom cards with 0 questions.
- The `where.category` filter in `buildWhereClause` only permitted exact string matching, failing to resolve alias variants.

### 3. Multiplayer Question Timer Freeze at 11s–12s
- Navigating from `/arena/:arenaId` to `/play/:arenaId` caused `/arena` to close its WebSocket (`wsLobby`) while `/play` connected a new WebSocket (`wsPlay`).
- On cloud reverse proxies (Render / Cloudflare), the TCP close event for `wsLobby` propagated with an 8–10 second delay.
- In `arenaWs.ts`, `close(ws)` blindly invoked `room.handlePlayerDisconnect(playerId)` without verifying whether the closing socket was still the player's active socket.
- This stale close event set `player.ws = null` and `player.isOnline = false` for the player who was actively playing on `wsPlay`, stopping all subsequent `tick` packet broadcasts (freezing the timer at 11s–12s on a 20s round).
- The client in `useArenaSocket.ts` lacked a local fallback countdown, depending 100% on discrete incoming server ticks.

## 🛠️ Action Plan & Implementation

### 1. Category Selection & Persistence (`Lobby`, `Lobby.css`, `Arena`, `arenaWs`)
- **Interactive UI in `CreateArenaModal`**:
  - Added native checkbox and interactive toggle badge (`✓ Inclus` / `+ Exclu`) on every category card header.
  - Added bulk action controls in section header: `✓ Tout cocher` and `✕ Tout décocher`.
  - Added live selection counter: `(X / Y sélectionnées)`.
  - Added `.category-card--inactive` visual styling (0.5 opacity, grayscale filter, disabled difficulty pills).
  - Enforced client-side validation preventing arena creation when zero categories are selected.
- **API & WebSocket Persistence**:
  - Explicitly transmitted `categories: settings.categories` in `POST /arenas`.
  - Synchronized `arena.categories` and `arena.difficulty` in `arenaWs.ts` (`open`) and `Arena/index.tsx`.

### 2. Canonical Deduplication & Alias Resolution (`questions.ts`, `types`, `Arena`)
- **Canonical Normalization (`getCanonicalKey`)**: Reconciled accents, ampersands, dashes, and casing to unify slugs and raw names.
- **Phantom Card Elimination**: Filtered out empty categories (`count > 0`), strictly aligning the arena on the 14 actual database categories.
- **Variant Query Resolution (`getCategoryQueryVariants`)**: Extended `buildWhereClause` to match questions by slug, full name, or alias variants (`in: variants, mode: 'insensitive'`).
- **Metadata & Icons**: Added missing emoji badges and labels for `Animaux & Dinosaures` (🦕), `Jeux Vidéo` (🎮), `Sports` (⚽), and `Mythologie & Légendes` (🏛️).

### 3. Timestamp-Authoritative Timer & WebSocket Lifecycle Hardening (`arenaWs.ts`, `roomManager.ts`, `useArenaSocket.ts`)
- **Socket Identity Verification on Close**:
  - In `arenaWs.ts` (`close(ws)`), if `player.ws && player.ws !== ws`, the closure is ignored because a newer active socket exists.
  - In `roomManager.ts` (`handlePlayerDisconnect(id, closingWs?)`), validated socket identity before marking players offline.
  - Automatically re-attached `player.ws = ws` and set `player.isOnline = true` on any incoming player message.
  - Added Ping/Pong protocol support (`type: 'ping'` -> `type: 'pong'`).
- **Timestamp-Authoritative Server Timer**:
  - Exact formula: `this.timeLeft = Math.max(0, roundTime - Math.floor((Date.now() - this.roundStartTime) / 1000))`.
  - Completely immune to event-loop drift; guarantees reliable invocation of `endRound()`.
- **Resilient Client-Side Countdown & Watchdog**:
  - Added `roundDeadlineRef` updated on `new_round`, `room_state`, and `tick`.
  - Local 250ms interval maintains smooth second-by-second countdown to 0s even during network jitter.
  - Self-healing watchdog: requests round sync via `requestCurrentRound()` if local timer reaches 0s without receiving `round_end` after 1.5s.
  - Automatic 15s ping heartbeat prevents cloud reverse proxies from dropping idle connections.
