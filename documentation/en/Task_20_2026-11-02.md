## Objective
1. **Fix overwriting of visual questions during Excel import**:
   - In the import template `smik_party_questions_template.xlsx`, visual questions (such as all 195 countries in the "Drapeaux" sheet) share identical question text (`text: "Quel est ce drapeau ?"`), while differing by their image (`imageUrl`) and answer (`answer`).
   - The previous import routine looked up existing records solely by prompt string (`where: { text: questionText }`) across the whole database, inadvertently overwriting each previous entry and collapsing 195 flags into a single record.
2. **Create `AGENTS.md`**:
   - Formalize operational guidelines and constraints for AI agents working on this project.
   - Enforce mandatory bilingual documentation (French and English) in the `documentation/` directory for every task.

## Implementation
- **Robust Excel import deduplication in `import.ts`**:
  - Image-based matching handles distinct media while maintaining idempotency:
    ```typescript
    if (imageUrl) {
      existing = await prisma.question.findFirst({
        where: {
          category: { equals: category, mode: 'insensitive' },
          imageUrl,
        },
      })
      if (!existing) {
        existing = await prisma.question.findFirst({
          where: {
            category: { equals: category, mode: 'insensitive' },
            text: { equals: questionText, mode: 'insensitive' },
            answer: { equals: answer, mode: 'insensitive' },
          },
        })
      }
    }
    ```
  - All 195 flag questions are now stored independently without overwriting.
- **`AGENTS.md` Setup**: Standardized repository guidelines for AI coding agents with strict bilingual documentation requirements.
