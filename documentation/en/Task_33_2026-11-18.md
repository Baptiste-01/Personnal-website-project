# Task 33: Sidebar Navigation, Multi-Game Hub, Suspended Questions Moderation & Admin User Management

- **Date:** 2026-11-18
- **Author:** Antigravity & Baptiste-01
- **Status:** Completed

---

## 🎯 Objective

1. **Modern & Collapsible Sidebar Navigation (`AppSidebar`)**:
   - Consolidate top bar actions into an integrated, responsive navigation sidebar across all main public views.
   - Core navigation items:
     - **Arenas & Lobbies (`/`)**: Direct lobby access, active games listing, match creation.
     - **Games Catalog (`/games`)**: Dedicated hub preparing the multi-game future of Smik Party.
     - **Administration / Questions (`/admin`)**: Question bank, moderation, and user management.
     - **User / Profile (`/profile` or `/login`)**: Player profile, XP progression, level tracking, saved templates, and history.
     - **Audio & Ambient Controls**: Compact sound theme controls in the sidebar.
   - Dual layout modes:
     - **Expanded Mode (260px)** with descriptive subtitles, labels, and status badges.
     - **Collapsed Mode (72px)** with clean icon-only display and tooltips, persisting preference in `localStorage`.
     - **Responsive Mobile Mode (< 860px)** with a clean slide-in drawer with backdrop.

2. **Resolution of UI Overlaps (Back, Mute, Theme Buttons)**:
   - Eliminate collision where the fixed floating hamburger trigger hovered directly over top-left UI elements (e.g., "Mute" button in Lobby, "← Retour au Lobby" in Admin, and profile back buttons).
   - Implement an inline top navigation bar (`.app-mobile-topbar`) on mobile that maintains clean separation without overlapping any page controls.
   - Synchronize CSS breakpoints (`max-width: 860px`) between `MainLayout.css` and `Lobby.css` to hide duplicate navigation controls cleanly.

3. **Multi-Game Architecture Preparation (`GamesHub` & `games.ts`)**:
   - Establish the extensible `GAME_CATALOG` data model and dedicated `/games` catalog previewing future titles (FlashGuess, BombParty, Blindtest Musical, Quiz Royale, Duo Co-op).
   - Interactive rules modal with feature list and community voting (« Support this game »).

4. **Dedicated Admin Space for Suspended Questions**:
   - Give complete purpose to the admin in-game mute button ("🔇 Mettre en sourdine") introduced in Task 32.
   - Implement a dedicated tab navigation in `/admin`: `Banque & Import / Export` and `Questions Suspendues`.
   - Real-time alert badge in `AppSidebar` for administrators (`⚠️ <count>`) pulsing red when suspended questions exist.
   - Comprehensive moderation panel:
     - View suspended questions with reason, timestamp, official answer, and accepted alternatives.
     - ✏️ **Edit & Reactivate**: Modal allowing editing of text, answer, accepted variants, category, and difficulty, with immediate reactivation into arenas.
     - 🔊 **Direct Reactivation (Unmute)**: Reactivates the question with one click.
     - 🗑️ **Permanent Deletion**: Permanently deletes faulty questions from the database.

5. **Comprehensive User Management in Admin (Dedicated Page & Actions)**:
   - Restructure Admin into two primary pages via top header navigation tabs:
     - **❓ Questions (`/admin`)**: Question banks and live moderation.
     - **👥 Users (`/admin/users`)**: Dedicated player accounts dashboard.
   - Community KPI cards: Total accounts, active administrators, aggregate games played, and community XP.
   - Real-time search by username/display name, role filters (`All`, `Admins`, `Players`), and multi-column sorting.
   - Safe administrative actions with in-app confirmation modals:
     - 🗑️ **Permanent Account Deletion** with Prisma cascading delete (sessions, achievements, history, templates) and self-deletion guard.
     - 🔄 **Statistics Reset** (Level 1, 0 XP, 0 games/wins, game history purge).
     - 🛡️ **Admin Role Grant / Revocation** with explicit confirmation dialog and self-demotion protection.
