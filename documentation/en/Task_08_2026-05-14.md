## Objective

   - `apps/api/routes/questions.ts`: question query and filtering routes.

2. Develop frontend admin dashboard (`apps/web/src/pages/Admin`) with drag-and-drop file upload, row preview, and import feedback.
3. Update `STARTUP.md` with question ingestion instructions.
