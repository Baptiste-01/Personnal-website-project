## Objective

## Action Plan
1. Add optional `imageUrl String?` attribute to Prisma `Question` model.
2. Update database seed (`seed.ts`) with illustrated sample questions.
3. Update Excel importer (`apps/api/routes/import.ts`) to ingest image URLs.
4. Integrate responsive image rendering and lightbox zoom in `FlashGuess`.
5. Update Admin tables and shared contracts.

- Configured Excel importer to recognize image column aliases (`image`, `imageUrl`, `photo`, `illustration`).
- Built responsive image display with lightbox zoom modal in `FlashGuess`.
- Updated Admin question statistics table to display thumbnail previews.
