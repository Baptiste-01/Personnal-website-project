# Task 22: Removal of Hints and Tags from In-Game Question Display

- **Date:** 2026-11-03
- **Author:** Antigravity & Baptiste-01
- **Status:** Completed

---

## Objective

1. **Definitive removal of hints during gameplay**:
   - Remove the "Show hint" button and the hint text display during FlashGuess rounds.
   - Clean up state `showHint` and its listeners in the frontend component.
2. **Total suppression of tags and metadata from gameplay display**:
   - Remove category badges (`fg-cat-badge`) and subcategory/tag badges (`fg-tags-row`, `#tag`) during gameplay.
   - Ensure players **exclusively** see the question text and its associated image (if present), without any clues or spoilers.
3. **Anti-cheat WebSocket hardening (Backend)**:
   - Clean up the WebSocket `question` payload broadcast during `new_round` and `getState` events to send only `id`, `text`, and `imageUrl` (excluding `hint`, `tags`, `category`, and `difficulty`).

---

## Action Plan

1. **Frontend FlashGuess (`apps/web/src/pages/FlashGuess`)**:
   - Delete `showHint` state and round reset logic.
   - Delete `.fg-question-meta` container (category and tags).
   - Delete `.fg-hint-btn` button and `.fg-hint` paragraph.
   - Purge obsolete CSS classes in `FlashGuess.css`.
2. **Shared Types (`apps/web/src/types/index.ts`)**:
   - Make `category`, `difficulty`, `hint`, and `tags` optional on the `Question` interface.
3. **Backend WebSocket (`apps/api/ws/roomManager.ts` & `apps/api/routes/arenaWs.ts`)**:
   - Sanitize the `question` object sent to clients: only send `{ id, text, imageUrl }`.
4. **Technical Verification & Build**:
   - Run frontend build (`bun run build`).
   - Validate backend TypeScript types (`bun x tsc -p apps/api/tsconfig.json --noEmit`).

---

## Implementation

- **Minimalist, Focused Gameplay Screen**:
  - The central prompt card (`.fg-prompt`) now exclusively renders the question text (`.fg-prompt-text`) and the image if present (`.fg-question-image-wrapper` with modal zoom).
  - No hints, category tags, or badges are visible in the game UI.
- **Enhanced Anti-Cheat Protection**:
  - The server no longer leaks hints, tags, categories, or difficulty values in WebSocket frames sent to browsers.
