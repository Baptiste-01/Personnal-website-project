## Objective

This task consolidates all major enhancements to the Admin dashboard for question management and data structure optimization:

1. **Full Question Catalog Export (Admin)**:
   - Provide administrators with the ability to download all questions stored in PostgreSQL.
   - Offer two direct export formats: multi-sheet Excel workbook (`.xlsx`) and structured Markdown document (`.md`).
2. **Markdown File Import Support (`.md` / `.markdown`)**:
   - Accept standard Markdown text files with automatic detection of section headers (`# Category`) and markdown tables.
   - Support deduplication, optional tags, and robust difficulty normalization.
3. **Interactive Visual Preview with Configurable Option**:
   - Offer a pre-import checkbox ("Automatically show visual preview of questions after import").
   - Display a conditional banner if the checkbox was inactive ("Would you like to view the visual preview?").
   - Render an interactive card grid with expandable image modal zoom, question text, answers, tags, and real-time filters.
4. **Complete Removal of the 'Indice' (Hint) Column Site-Wide**:
   - Following in-game hint removal (Task 22), purge the `indice` column from Excel templates, Markdown/Excel exports, forms, reference tables, and TypeScript types.
5. **Reliable Export Downloads (Vite Proxy & Blob Stream)**:
   - Fix Vite proxy SPA `bypass` that intercepted `<a download>` requests carrying `Accept: text/html` and served `index.html`.
   - Implement programmatic `fetch()` and Blob downloads (`window.URL.createObjectURL(blob)`).

## Action Plan

1. **Backend API (`apps/api/routes/import.ts`)**:
   - Build `parseMarkdownTables` parser.
   - Implement `GET /admin/export` supporting `?format=xlsx` and `?format=md`.
   - Update `GET /admin/template` to generate a 6-column template (`question`, `réponse`, `réponses_acceptées`, `difficulté`, `image_url`, `tags`).
   - Remove the `indice` column from `.md` and `.xlsx` exports.
   - In `POST /admin/import`, ignore `indice` and assign `hint: null`.
2. **Admin Frontend (`apps/web/src/pages/Admin/index.tsx`)**:
   - Accept `.md` files in dropzone.
   - Add `handleDownloadExport` and `handleDownloadTemplate` using `fetch()` Blob downloads.
   - Remove `indice` row from specification table and Markdown code example.
   - Remove hint display from preview cards.
   - Add filterable question cards with image modal zoom.
3. **Vite Configuration (`apps/web/vite.config.ts`)**:
   - Restrict HTML bypass strictly to client SPA paths `/admin` and `/admin/` to allow all API subroutes (`/admin/export`, `/admin/template`, etc.) to reach the backend.
4. **Shared Types (`apps/web/src/types/index.ts`)**:
   - Remove obsolete `hint` field from `Question` interface.
5. **Technical Verification**:
   - Compile with `bun run build` and check types with `bun x tsc -p apps/api/tsconfig.json --noEmit`.
