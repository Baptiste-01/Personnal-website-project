## Objective
Design and implement the first playable version of the **FlashGuess** multiplayer game mode, including the lobby, game arena, Prisma data models, and database seed script.

## Action Plan
1. Define database models in Prisma (`Game`, `Round`, `Question`, `Answer`).
2. Write initial database seed script (`packages/database/prisma/seed.ts`) with question sets.
3. Build React lobby interface (`apps/web/src/pages/Lobby`) for game preparation.
4. Build game arena (`apps/web/src/pages/Arena`) and FlashGuess view (`apps/web/src/pages/FlashGuess`).
5. Create shared SVG icon library (`apps/web/src/components/Icons.tsx`).
6. Wire game loop to Bun API.

## Implementation
- Implemented full FlashGuess game cycle: countdown timer, question prompt, answer submission, streak multipliers, and scoreboard.
- Seeded diverse initial question sets into PostgreSQL.
- Implemented reusable SVG icon pack for UI gamification (trophies, timers, crowns).
- Created dedicated style sheets (`FlashGuess.css`, `Arena.css`, `Lobby.css`).
