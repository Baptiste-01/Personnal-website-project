## 🎯 Objective

Task 32 addresses both content curation and in-game competitive feedback through two main parts:

1. **Part 1: Exclusive In-Game Admin Action to Mute Erroneous Questions**:
   - Provide an in-game action button visible **strictly and exclusively to administrators** (`isAdmin: true`) during FlashGuess arena matches (`/play/:arenaId`).
   - Instantly mute questions containing errors, typo issues, invalid answers, or broken images, filtering them out permanently and in real-time (`mutedQuestionsStore`, DB tag `'sourdine'`, WebSockets).
2. **Part 2: Streak Indicators, First-to-Answer Top Speed Counter, and Complete End-Game Statistics**:
   - **Streak Indicator**: Real-time tracking of consecutive correct answers for each player (`🔥 xN`), featuring graduated visual feedback (amber x2-x4, animated fiery red/violet x5+) and score multipliers (x1.5 at 3+, x2.0 at 5+).
   - **Top Speed Counter (1st to Answer)**: Automatic server-side detection and counting of the player who finds the correct answer first in each round (`⚡ N`). Displayed on live badges and celebratory feedback notices ("⚡ 1st to answer!").
   - **Comprehensive End-of-Game Statistics Dashboard**:
     - Upgraded results screen (`roomStatus === 'finished'`) with an animated podium.
     - **Hall of Fame Awards**: Distinction trophies awarded dynamically (👑 Champion, ⚡ Fastest Player, 🔥 Legendary Streak, 🎯 Accuracy Sniper).
     - **Personal Statistics Grid**: Final score & rank, accuracy percentage, top speed count, highest streak record, average reaction time (`⏱️`), and final streak.
     - **Full Multiplayer Summary Table**: Exhaustive 7-column comparison (Rank, Player, Score, Correct answers, ⚡ 1st found, 🔥 Max streak, ⏱️ Average response time).

## 📋 Action Plan

1. **Backend Engine (`roomManager.ts` & `mutedQuestions.ts`)**:
   - Extend `PlayerSummary` and `PlayerSession` interfaces with `firstAnswersCount`, `correctAnswersCount`, `totalAnswersCount`, and `averageReactionTime`.
   - Initialize and reset counters upon player join, game start (`startGame`), and return to lobby (`resetToLobby`).
   - In `submitAnswer()`: detect whether the player was first to find the answer (`isFirst = !players.some(p => p.id !== playerId && p.answeredCorrectly)`). Increment `firstAnswersCount`, `correctAnswersCount`, and store reaction times.
   - In `endRound()`: increment `totalAnswersCount` for all active players and reset `streak` to 0 for players who missed.
   - Broadcast `isFirst`, `firstAnswersCount`, and `bestStreak` within `answer_result` and `player_answered`.
2. **Types & WebSocket Hook (`types/index.ts` & `useArenaSocket.ts`)**:
   - Synchronize `PlayerSummary` client-side types with new statistical metrics.
   - Extend `useArenaSocket` to track `wasFirstAnswerer` and update player lists upon receiving `player_answered`.
3. **FlashGuess UI & CSS (`FlashGuess/index.tsx` & `FlashGuess.css`)**:
   - Render live streak (`🔥 xN`) and top speed (`⚡ N`) badges on the sidebar player list.
   - Render current active streak with multipliers and top speed counts in the `fg-stats` bottom bar.
   - Add `⚡ 1st to answer!` highlight tags in answer confirmation notices and reveal phases.
   - Redesign the end-game results view with:
     - 4 distinction awards (Champion, Fastest, Legendary Streak, Precision Sniper).
     - Personal player stat summary metric cards.
     - 7-column comprehensive multiplayer leaderboard table.
4. **Verification & Documentation**:
   - Run complete TypeScript typechecks (`tsc`) across `apps/web` and `apps/api`.
   - Run automated unit test script validating stats collection, streaks, and speed tracking.
   - Update bilingual documentation files and root tables.
