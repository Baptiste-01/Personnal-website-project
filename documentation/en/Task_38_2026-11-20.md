## 🎯 Objective

Following visual inspection and real-world usage on the live platform, several significant layout and ergonomic issues were addressed:
1. **Truncated Sidebar / Incomplete Viewport Height**:
   - Due to a CSS conflict between `position: sticky; height: 100vh;` and `overflow-x: hidden` on the parent container `.app-shell`, the sidebar scrolled away with the window instead of remaining pinned.
   - When page content exceeded viewport height, the sidebar scrolled out of view, leaving an empty gap beneath the sidebar footer.
2. **Broken & Misaligned Collapsed Sidebar Mode**:
   - In collapsed mode (72px width), the header forced both the 40px brand icon and the 32px collapse toggle onto a single row, causing horizontal overflow and icon clipping.
   - Navigation links lost their centered alignment.
   - Audio and theme switcher buttons were squeezed side-by-side with no breathing room.
   - The collapsed user card lacked clarity and proper alignment.
3. **Collapse/Expand Control via the Gamepad Icon Adjacent to Smik Party**:
   - Make the gamepad icon adjacent to Smik Party directly interactive to collapse the sidebar when expanded, and expand it when collapsed.
4. **Text Overload and Truncation in Navigation Items**:
   - Overly long titles and subtitles caused constant ugly text truncation (`Arènes & ...`, `Catalogue d...`, `Parties mult...`).
   - The theme button (`Néo-Arcade`) wrapped across two lines (`Néo-` / `Arcade`) with unbalanced widths.
5. **Redundant "My Profile" Navigation Tab**:
   - The "My Profile" tab in the central navigation list duplicated the permanent user profile card in the sidebar footer (`as-footer`).
6. **Duplicate Audio and Theme Controls (Header vs Sidebar)**:
   - The `AudioThemeControls` component appeared simultaneously in the Lobby top navigation bar (`lobby-nav`) and in the sidebar (`AppSidebar`), creating redundant "Mute" and theme buttons.
   - The Lobby top bar also duplicated links to Administration and Profile.

## 📋 Action Plan

1. **Full-Height App-Shell Architecture (`MainLayout.css`)**:
   - Apply standard modern web application layout (App-Shell Pattern): `.app-shell` set to `100vh / 100dvh` with `overflow: hidden`.
   - `.as-sidebar` pinned to `height: 100%; max-height: 100%;` with internal scrolling for links when needed.
   - Independent vertical scrolling delegated to the main view container (`.app-shell-main` with `overflow-y: auto; overflow-x: hidden;`).
2. **Complete Overhaul of Collapsed State (`AppSidebar.tsx` & `AppSidebar.css`)**:
   - Collapsed header: vertical centering with 40x40px clickable gamepad brand icon and centered `>>` expand button.
   - Collapsed navigation tiles: centered 48x48px square tiles with hover glow, high-visibility active state, native tooltips, and miniature status dots (green for live arena, red for suspended questions).
   - Collapsed audio/theme controls: compact 38x38px vertical orientation.
   - Collapsed footer: centered 38x38px player avatar with admin crown and compact logout/login button.
3. **Removal of Redundant "My Profile" Tab**:
   - Remove profile link from `navItems`. Profile navigation is centralized on the sidebar footer card.
4. **Definitive Removal of Duplicate Controls**:
   - Remove redundant `<nav className="lobby-nav">` from `Lobby/index.tsx` and eliminate unused `AudioThemeControls` import.
   - Adjust top spacing on `.lobby-header` in `Lobby.css`.
   - Support `orientation?: 'horizontal' | 'vertical'` in `AudioThemeControls.tsx` and `AudioThemeControls.css`.
5. **Text Density Streamlining & Truncation Elimination**:
   - Replaced verbose labels with crisp, arcade-friendly single words: `Arènes` (instead of `Arènes & Salons`), `Jeux` (instead of `Catalogue de Jeux`), `Admin` (instead of `Administration`).
   - Removed cumbersome secondary subtitles (`Parties multijoueurs`, `FlashGuess & À venir`, etc.) in favor of clean native hover tooltips.
   - Converted navigation links into single-line tiles (`.as-nav-link-main` + badge) with 0 text truncation.
   - Balanced audio/theme buttons 50/50 (`flex: 1 1 0; min-width: 0; white-space: nowrap; font-size: 11px;`) to eliminate wrapping (`Néo-` / `Arcade`).
6. **Dynamic Theming for Logo & "Party" Word**:
   - Replaced all hardcoded blue hex values (`#3b82f6`, `#60a5fa`, `#1d4ed8`, `#1e3a8a`, etc.) with theme CSS variables (`var(--color-accent)`, `var(--color-accent-hover)`, `var(--color-accent-dark)`, `var(--color-accent-glow)`).
   - Brand logos (hero header, sidebar, mobile topbar), gradient "Party" title, arcade action buttons ("Nouvelle arène", "Rejoindre", login), and matrix background grid dynamically reflect active theme (retro blue, dark zinc purple, cyberpunk hot pink).
7. **Subtle & Retro Pixel Art Background Animation (Video Games & Anime)**:
   - Designed and integrated `ArcadeBackground` ambient component (`apps/web/src/components/ArcadeBackground/ArcadeBackground.tsx` & `.css`).
   - Integrated non-intrusive animated retro vignettes:
     - 8-bit pixel clouds gently drifting across the background parallax sky.
     - High-altitude Space Invader patrol with reactive accent glow.
     - Floating Mario question block `[ ? ]` with rotating golden coin.
     - Retro combat duel repositioned to the bottom-left (`ab-combat-bottom-left`):
        - Martial arts duel set along the bottom horizon baseline: fighter in gi (black hair, red headband), animated Hadouken beam, and guarding rival ninja.
      - Endless stationary runner at bottom-right (`ab-bottom-runner-zone`) featuring the white-haired, brown-eyed hero:
        - Removed the awkward curved ponytail hook behind the head in favor of a clean, short anime haircut exposing the neck naturally, paired with **beige crewneck sweatshirt** (`#f5f2ea`), **blue denim jeans** (`#2563eb`), and detailed **brown eyes** (`#78350f`).
          - Eliminated ground-level cartwheels to guarantee the hero runs flat and stable along the horizon without ever clipping through the ground line.
          - Exotic flips are triggered **strictly when leaping over obstacles and enemies**: **Frontflip (Salto avant 360°)** over the beetle hazard and **High Backflip (Salto arrière 360°)** over the tall Mario pipe.
          - Continuous single-sprite architecture (`ab-sh-sprite`): definitively prevents jump disappearance and ghost limb overlays (no fragile layer hiding or toggling).
        - Horizontally stationary stance (`right: 175px`): the hero runs smoothly and continuously on the ground baseline without traversing across the screen or clipping through the ground.
        - Dynamic randomized obstacle spawner scrolling right-to-left:
          - **4 distinct obstacle variants**: retro beetle (`beetle`), green Mario warp pipe (`pipe`), **sharp ground spikes** (`spikes`), and **ground pit / hole in the floor** (`pit`) cutting deep into the void below the baseline.
          - **Randomized cadence**: unpredictable spawn intervals (between 2.8s and 4.6s) delivering a constantly varied, organic arcade runner sequence.
          - **Reactive & synchronized acrobatic dodges** (`heroSaltoFrontflip` / `heroSaltoBackflip`): hero dynamically triggers a frontflip or backflip exactly as each obstacle arrives, sticks the landing cleanly with zero residual ground spin, and runs smoothly on the baseline all the rest of the time.
      - Discrete bottom pixel skyline.
   - 100% preservation of readability and ergonomics: placed strictly in background (`z-index: 0; pointer-events: none;` and soft 40-50% opacity), leaving interactive game cards and modal dialogs perfectly crisp and readable in foreground (`z-index: 1+` with backdrop-filter).
8. **Local Server Restoration Without Breaking Cloud Deployment**:
   - Integrated Render cloud deployment scripts (`build:api`, `start:api`) while aligning local dev scripts (`dev`, `dev:api`, `dev:web`) in `package.json`.
   - Robust `.env` resolution in `apps/api/lib/prisma.ts` searching project root or current working directory automatically.
   - Smart URL resolver in `apps/web/src/utils/config.ts`: targets Render cloud backend on Vercel deployment while retaining local Vite reverse-proxy (`localhost:3000`) for development.
   - Safe table initialization via `bootstrapDatabase` and resilient routes (`/arenas`).
9. **Bypassing Windows AppLocker / Antivirus Block on `vite.exe`**:
   - On Windows, Bun generates unsigned shim binaries in `node_modules/.bin/` (`vite.exe`) that Windows Defender Application Control blocks with `bun: unknown error:`.
   - Fixed in `apps/web/package.json` by invoking Vite's official entrypoint script directly with the trusted Bun binary: `bun ./node_modules/vite/bin/vite.js --host`.
   - Parallel execution via `bun run dev` (API on port 3000 + Vite on port 5173) is 100% verified and operational.
