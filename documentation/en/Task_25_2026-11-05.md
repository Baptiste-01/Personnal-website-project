# Task 25: CSV Import/Export, Question/Category Deletion & Strict Difficulty Ordering (Easy, Normal, Hard)

- **Date:** 2026-11-05
- **Author:** Antigravity & Baptiste-01
- **Status:** Completed

---

## Objective

1. **Question Export in CSV (`.csv`)**:
   - Allow administrators to export the full question catalogue in standard RFC 4180 CSV format.
   - Include a UTF-8 BOM (`\uFEFF`) to prevent accented character corruption when opening in Microsoft Excel on Windows.
2. **Universal CSV Import**:
   - Support direct upload of `.csv` files via dropzone or file picker.
   - Automatically detect delimiters (comma `,` or semicolon `;`).
   - Support multi-category imports using the `catégorie` / `category` column, or file-name based categorization for single-category files.
   - Accurately process multiline values and escaped double quotes (`""`).
3. **Question & Category Deletion from Database**:
   - Provide administrators with a safe and simple way to delete single questions directly from the preview cards.
   - Allow deleting entire categories and all associated questions from the Admin database statistics view, with confirmation prompts.
4. **Strict Difficulty Ordering**:
   - Guarantee a deterministic difficulty ordering across the entire site and admin interface: **Easy**, **Normal**, **Hard**.
   - Standardize category stats breakdowns, preview filter buttons, and question listing API order.

---

## Action Plan

1. **Backend API (`apps/api/routes/import.ts`)**:
   - Build `parseCsv` parser with delimiter autodetection (`,` vs `;`), multiline field parsing, quote escaping, and category grouping.
   - Accept `.csv` files in `POST /admin/import`.
   - Implement `?format=csv` in `GET /admin/export` with standard headers (`catégorie`, `question`, `réponse`, `réponses_acceptées`, `difficulté`, `image_url`, `tag`), RFC 4180 escaping, and UTF-8 BOM.
   - Implement `DELETE /admin/questions/:id` to remove a specific question by ID.
   - Implement `DELETE /admin/categories/:category` to cascade delete all questions in a category and the category entry.
   - Implement `GET /admin/questions` to fetch questions sorted by category and difficulty rank (`Easy` -> `Normal` -> `Hard`).
   - Enforce difficulty order sorting in `GET /admin/stats`.
2. **Admin Frontend (`apps/web/src/pages/Admin/index.tsx`)**:
   - Allow `.csv` extension in `handleFile` and file input.
   - Update `handleDownloadExport` to handle `'csv'`.
   - Add the CSV export button styled with blue gradient.
   - Add category deletion buttons (`🗑️`) with confirmation dialogs.
   - Add "🔍 Gérer toutes les questions" to load database questions into the preview section.
   - Add question deletion button (`🗑️`) on each preview card.
   - Enforce difficulty sorting (`Easy`, `Normal`, `Hard`) in category badges and preview filter bar.
3. **Styles (`apps/web/src/pages/Admin/Admin.css`)**:
   - Add `.btn-export--csv`, `.btn-delete-cat`, `.btn-manage-db`, and `.preview-card-delete-btn`.
4. **Technical Verification**:
   - Verify frontend build (`bun run build`) and backend type safety (`bun x tsc -p apps/api/tsconfig.json --noEmit`).

## Implementation

- **CSV Import & Export Engine**:
  - `parseCsv` cleanly parses CSV files regardless of delimiter (`,` or `;`).
  - `/admin/export?format=csv` produces RFC 4180 CSV with UTF-8 BOM.
- **Secure Management & Deletion**:
  - `DELETE /admin/questions/:id` and `DELETE /admin/categories/:category` allow single-click removal with confirmation.
- **Strict Difficulty Ordering (Easy, Normal, Hard)**:
  - Unified rank mapping (`facile/easy` = 1, `moyen/normal/medium` = 2, `difficile/hard` = 3) applied to backend queries and frontend counters/filters.
