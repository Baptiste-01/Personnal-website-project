## Objective
1. **Independent Mythology Category**: Completely detach *Mythology & Legends* from the *History* category.
2. **Dynamic Subcategory Tags System**:
   - Utilize the `tags` column from the questions Excel template (`smik_party_questions_template.xlsx`) (e.g., `Grec`, `Romain` for mythology, `Europe`, `Asie` for capitals).
   - Strictly avoid hardcoding questions or tags in the source code: the database and Excel import remain the single source of truth.
3. **Unified Selection UX (No Extra Tabs)**:
   - Display subcategory chips directly beneath each category card within the **Categories** tab.
   - Default "✨ All" button active: when no tag is selected, no subcategory filter is applied, keeping all category questions eligible.
   - When specific tags are selected, only questions matching at least one tag are drawn.
4. **Real-time Question Counter**: Instant calculation of available questions matching the active combination of categories, subcategories, and difficulty levels.
5. **Full Mobile Responsiveness**:
   - Resolve modal overflowing and inaccessible submit actions in the Lobby arena creation dialog.
   - Optimize the Arena setup page (`/arena/:id`) on mobile viewports (natural full-page scroll, compact player strip, swipeable labeled tabs, non-overflowing chip wraps).

## Action Plan
1. **Prisma Schema & Database**:
   - Add `tags String[] @default([])` to `Question` and `Arena`.
   - Create `Category` model (`id`, `slug`, `name`, `icon`, `tags String[]`).
   - Sync PostgreSQL database schema (`bun run db:push`).
2. **Backend API (`apps/api`)**:
   - Enhance `import.ts` to parse, clean, and associate Excel tags with questions and categories.
   - Update `buildWhereClause()` in `routes/questions.ts` to support `catTags` (e.g. `mythologie:Grec+Romain`) with automatic fallback to all questions when no tag is specified.
   - Provide `GET /questions/categories` (with tag aggregation and counts) and `GET /questions/count`.
3. **Frontend Web (`apps/web`)**:
   - Remove dedicated `# Tags` tab and manual creation forms from Arena settings.
   - Embed subcategory tag chips with count badges and "✨ All" reset button under each category card.
   - Pass `catTags` to FlashGuess and render subcategory badges above active questions.
   - Overhaul responsive CSS for `CreateArenaModal` (`Lobby.css`) and Arena setup (`Arena.css`).
4. **Technical Verification**:
   - Ensure zero TypeScript compiler errors (`tsc -b` and `tsc --noEmit`).
   - Confirm production Vite build speed and integrity.

## Implementation
- **Dynamic Data Model**: Native PostgreSQL text array (`text[]`) queried through Prisma's `hasSome` filter.
- **Automated Excel Import**: Automatic delimiter parsing (`,`, `;`, `/`) and normalization without any hardcoded questions or tags.
- **Streamlined Configuration UI**: Interactive subcategory pills per category card with instant reset and live question availability feedback.
- **In-Game Meta Badges**: Visual subcategory tags rendered over question cards during gameplay in FlashGuess.
- **Comprehensive Mobile Responsiveness**:
  - Lobby Modal: Adaptive height (`max-height: calc(100dvh - 32px)`), internal touch scrolling, and sticky bottom action buttons guaranteeing access to "Create and Join".
  - Arena Page: Continuous full-screen scrolling (`min-height: 100dvh`), compact player sidebar, visible tab labels with smooth horizontal touch scrolling, and `flex-wrap` protection against horizontal overflow.
- **Validated Quality**: 0 TypeScript errors across monorepo and production build generated in under 500 ms.
