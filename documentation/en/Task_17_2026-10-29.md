## Objective
Design and implement an immersive audiovisual and ergonomic experience (Axis 4 of the roadmap):
1. Autonomous procedural audio engine based on the Web Audio API (zero external assets, zero latency).
2. Global sound control (Mute/Unmute) and persistent multi-theme system (Neo-Arcade, Dark Zinc, Cyberpunk).
3. Celebratory end-game screen with dynamic 3D podium, confetti fireworks (`canvas-confetti`), and detailed performance metrics (accuracy %, best streak, average response speed).

## Action Plan
1. Install `canvas-confetti` and its TypeScript definitions.
2. Build native Web Audio synthesizer (`apps/web/src/utils/sound.ts`) synthesizing retro/arcade effects (correct answer chime, wrong answer buzzer, urgent countdown ticks, victory fanfare, UI taps).
3. Build theme manager (`apps/web/src/utils/theme.ts`) and declare corresponding CSS variables in `index.css` for `retro`, `dark`, and `cyberpunk` themes.
4. Create reusable `AudioThemeControls` widget and mount it into Lobby, Arena, and FlashGuess navbars.
5. Upgrade `FlashGuess` game loop:
   - Automated sound triggers during gameplay and last 5 seconds of the countdown.
   - Confetti bursts on answer streaks (streak >= 3).
   - Celebratory results view with 3-tier podium, medals, and metrics dashboard.
6. Verify TypeScript compilation and production Vite build.

## Implementation
- Implemented `SoundManager` in `sound.ts` with local storage persistence.
- Implemented `ThemeManager` in `theme.ts` and enriched `index.css` with 3 accessible color themes.
- Added `AudioThemeControls` with tactile sound feedback and one-click switching.
- Transformed FlashGuess results screen with dynamic podium, avatars, crowns, and metrics grid.
- Synchronized victory fanfare with double-cannon confetti fireworks.
- Verified strict TypeScript contracts and clean Vite build (`built in 383ms`).
