## 🎯 Objective

1. **Configurable Speedrun Mode & Per-Difficulty Timers**:
   - A dedicated toggle in the Arena "Timer" tab to activate Speedrun mode.
   - Individual selection for each targeted difficulty tier: `🟢 Easy (Facile)`, `🟡 Normal (Moyen)`, `🔴 Hard (Difficile)`. Unchecked difficulties retain the arena's standard question timer (e.g. 20s).
   - Independent accelerated countdown timers for each selected difficulty (e.g., `3s` for Easy, `5s` for Normal, and `8s` for Hard), configurable via interactive cards (quick pills and a 2s-20s slider).
   - Server authority: dynamic calculation of round duration per drawn question (`getQuestionSpeedrunTime`), real-time WebSocket distribution, and a pulsating dynamic badge `⚡ SPEEDRUN (Xs)` in `FlashGuess`.
   - Game Templates & URL sharing: save, load, and share custom per-difficulty timers (`diffSpeedrun=facile:3,moyen:5`).

2. **Real-Time Multiplayer Arena Chat System**:
   - Live in-game chat system accessible to all players joined in the same arena room.
   - Available seamlessly in both the pre-game arena lobby (`/arena/:arenaId`) and during active gameplay in FlashGuess (`/play/:arenaId`).
   - Rolling buffer of the last 50 messages maintained on the server (`GameRoom`) and hydrated upon initial join/reconnect via `room_state`, ensuring conversation persistence across route transitions.
   - Instant WebSocket broadcasting (`chat_message`).
   - Automated system milestones for player join, departure, game launch, and game conclusion with winner and score.
   - Complete `<ArenaChat />` UI component with a floating action button (FAB), unread message indicator, ephemeral toast preview bubbles when collapsed, colored avatar pills, isolated keyboard events (Enter key, 150-char limit), and quick reaction pills (`👏 GG`, `🔥 Trop fort`, `😂`, etc.).

## 📋 Action Plan

1. **Speedrun by Difficulty**:
   - Extend `GameSettings` with `difficultySpeedrunTimes: Record<string, number>`.
   - Implement `parseDifficultyTimesMap` and `serializeDifficultyTimesMap` in `apps/web/src/utils/tagFilter.ts`.
   - Backend (`roomManager.ts` & `arenaWs.ts`): implement `GameRoom.getQuestionSpeedrunTime(q)` and broadcast the resolved duration per question.
   - Frontend (`Arena`): difficulty configuration cards in the Timer tab with URL and Template synchronization.
   - Live game (`FlashGuess`): pulsating `⚡ SPEEDRUN (Xs)` badge and scaled countdown.

2. **Multiplayer Chat System**:
   - Backend (`roomManager.ts` & `arenaWs.ts`): define `ChatMessage`, maintain history on `GameRoom`, implement `addChatMessage()` (50-message cap, trimming, broadcast), dispatch system notifications, and expose chat in `getState()`.
   - Frontend (`useArenaSocket.ts` & `types/index.ts`): update type with `isSystem`, hydrate via `room_state`, and deduplicate messages.
   - UI Component `<ArenaChat />`: glassmorphic window, auto-scroll, preview toast bubbles, quick reactions bar, and FAB with unread badge.
   - Integration into `Arena` (lobby) and `FlashGuess` (gameplay with topbar toggle).
