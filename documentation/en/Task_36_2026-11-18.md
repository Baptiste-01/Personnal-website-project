Audit and finalize the entire application stack (Vercel Frontend and Bun/Prisma/Neon Backend API) for production deployment:

## 📋 Action Plan
1. **Dynamic Frontend Connectivity (`apps/web/src/utils/config.ts`)**:
   - Detect Vercel host (`*.vercel.app`) to default to the Render Cloud backend (`https://smik-party-api.onrender.com`).
   - Dynamic URL override via `?api=...` or `localStorage` with `setCustomApiUrl`.
2. **Metadata, HTML Titles & Fallback Routing (`apps/web`)**:
   - Official title `Smik Party — Jeux Multijoueurs en Temps Réel` and Open Graph metadata (`og:*`, `theme-color`).
   - Dynamic tab title (`document.title`) on all routes.
   - Wildcard fallback route `*` redirecting to `/`.
3. **Graceful Cold-Start & Offline Messaging (`Lobby`)**:
   - Friendly status message explaining Render free tier sleep mode (~45s), retry button, and interactive API URL modifier.
4. **Automatic Database Bootstrap (`apps/api/lib/bootstrap.ts`)**:
   - Verify PostgreSQL (Neon) connectivity.
   - Automatically seed default Administrator (`admin` / `Admin123!`) if no admin exists.
   - Seed initial questions and categories if the database is empty.
   - Create default main arena and reset orphaned room players.
5. **Docker & Production Start Configuration (`Dockerfile.api` & `index.ts`)**:
   - Run `prisma db push` automatically in Docker container before launching the API.
   - Healthcheck endpoints `/` and `/health`.
   - Universal CORS configuration (`origin: true`, `Authorization` header support).
