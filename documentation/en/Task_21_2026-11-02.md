## 📋 Action Plan & Architecture

1. **Server-Side In-Memory Room Engine (`GameRoom` & `RoomManager`):**
   - Room lifecycle management: `waiting` (lobby), `playing` (active round), `reveal` (answer reveal), `finished` (game over & podium).
   - Server-authoritative countdown clock.
   - Secure question distribution (**Strict Anti-Cheat**: neither the answer nor accepted alternative answers are sent to clients during active rounds).
   - Instant server-side answer evaluation (diacritic-insensitive, case-insensitive, whitespace trimmed), speed & streak point calculation.
   - Early round ending as soon as all connected players find the answer.
   - **45-Second Disconnection Grace Period:** Session and room preservation during page transitions, tab switches, and network reloads.
   - **Guaranteed Question Fallbacks (`FALLBACK_QUESTIONS`):** Absolute resilience even when PostgreSQL returns zero items or is unreachable.

2. **Elysia WebSocket Endpoint (`apps/api/routes/arenaWs.ts`):**
   - Mount `/ws/arena/:arenaId` on native Bun/Elysia HTTP/WS server.
   - Event handling: `join`, `toggle_ready`, `update_settings`, `start_game`, `submit_answer`, `restart_game`, `chat_message`, `request_current_round`, and graceful disconnects.
   - Live synchronization of connected player counts across REST API and PostgreSQL database.

3. **Unified Client WebSocket Hook (`useArenaSocket`) & Dynamic Host Resolution:**
   - Auto-connection and reconnection support, session-isolated guest identity generation (`sp_anon_id`, `sp_anon_name`).
   - Dynamic host resolution (`config.ts`) replacing all hardcoded `localhost:3000` URLs to enable multi-device and remote online gameplay.

4. **Free Forever Cloudflare Tunnel & Unified Reverse-Proxy:**
   - **Guaranteed 100% Free Forever:** Uses Cloudflare Quick Tunnels (`trycloudflare.com`), officially released by Cloudflare Zero Trust as permanently free with unlimited bandwidth. No account, no credit card, and no custom domain required.
   - **Single-Tunnel Vite Reverse Proxy:** Configured Vite's dev proxy to automatically route `/ws` (WebSockets) and API routes (`/auth`, `/arenas`, `/questions`, `/admin`, `/rooms`) to Elysia (`localhost:3000`). Exposing only port `5173` through the tunnel cleanly handles the entire web app, API, and WebSockets without port conflicts or CORS issues.
   - **Runner Script (`scripts/tunnel.ts`):** Detects or launches `tools/cloudflared.exe` and displays the shareable public link.

5. **User Interface Upgrades (`Arena/index.tsx` & `FlashGuess/index.tsx`):**
   - Live connected player list with individual "Ready" toggles.
   - Live multiplayer scoreboard in sidebar with real-time status chips (`⏳ Thinking`, `✅ OK`, `❌ Missed`).
   - 3-step celebratory podium screen and synchronized group replay.
