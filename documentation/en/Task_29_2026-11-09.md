## Objective

1. **Game Configuration Templates System**:
   - Allow players with registered accounts to save full game configurations (selected categories, category-specific difficulties, tags, fixed or infinite rounds mode, round count, time per round, max score target, player limit).
2. **Simplified Universal Multiplayer Sharing**:
   - Generation of unique, readable short sharing codes (e.g. `TMPL-7X2B`).
   - Generation of direct invitation URLs (`/?template=TMPL-7X2B`) enabling any player (guest or registered) to open the game with preloaded settings.
   - Community public catalog for discovering and cloning popular templates crafted by other players.
3. **Seamless Gameplay Integration**:
   - In the **Lobby** arena creation modal: single-click selection of personal or public templates, share code input, and a button to save the active configuration as a template.
   - In the arena room (**Arena**): room hosts can apply templates or save current arena settings, with instant real-time synchronization across all connected guests via WebSocket.
   - In the **Profile** page: a dedicated tab to view, rename, toggle public/private visibility, delete, or import templates by code.

## Architecture & Implementation

### 1. Database & Prisma Schema ([`packages/database/prisma/schema.prisma`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/packages/database/prisma/schema.prisma))

- Added `GameTemplate` model:
  - `id`: unique cuid identifier.
  - `name` & `description`: template name and optional description.
  - `shareCode`: unique indexed short code (e.g. `TMPL-8F2B`).
  - `isPublic`: public visibility flag for the community catalog.
  - `usageCount`: times played / popularity counter.
  - `settings`: full JSON configuration matching `GameSettings`.
  - `userId` & `user`: foreign key relation with cascade delete to `User`.
- Client regeneration via `bun run db:generate`.

### 2. Backend API ([`apps/api/routes/templates.ts`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/api/routes/templates.ts))

Modular Elysia router prefixed by `/templates` mounted in [`apps/api/index.ts`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/api/index.ts):
- `GET /templates/my`: retrieves templates owned by the authenticated user (via Bearer token).
- `GET /templates/public`: public catalog sorted by popularity (`usageCount`).
- `GET /templates/code/:shareCode`: resolves a template by its sharing code with optional usage counter increment (`?use=true`).
- `POST /templates`: creates a template and assigns an auto-generated unique `TMPL-XXXX` code.
- `PUT /templates/:id`: updates name, description, settings, or visibility (enforcing ownership or admin privileges).
- `DELETE /templates/:id`: securely deletes a template.
- `POST /templates/clone/:shareCode`: duplicates a community template into the user's personal account.

### 8. Fix Focus Loss & Auto-Deselect Glitch (3-Second Cycle)

- **Root Cause**:
  - Background silent polling in `Lobby` refreshed the arenas list every 3 seconds (`fetchArenas('silent')`), prompting a re-render of `Lobby`.
  - The modal close callback (`onClose`) was recreated on every render and included in the dependency array of a `useEffect` inside `CreateArenaModal` calling `inputRef.current?.focus()`.
  - As a result, every 3-4 seconds, focus was forcibly pulled from the template title input field back to the underlying arena name input.
- **Resolution ([`apps/web/src/pages/Lobby/index.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Lobby/index.tsx))**:
  - `inputRef.current?.focus()` now only executes on initial mount (`useEffect(..., [])`).
  - Added a stable `onCloseRef` for the `Escape` key listener.
  - Paused silent background polling whenever a modal (`CreateArenaModal` or `TemplateModal`) is open.
  - In [`apps/web/src/components/TemplateModal/TemplateModal.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/components/TemplateModal/TemplateModal.tsx), added autofocus to `saveNameInputRef` and prevented tab reset effects during typing.
