# 📚 Documentation du Projet - JKLM Clone

## 🌟 Présentation Générale
Ce projet est un jeu multijoueur en ligne en temps réel inspiré de la plateforme JKLM, centré sur la rapidité d'esprit, la culture générale et le vocabulaire (notamment le mode **FlashGuess**).

### 🛠 Stack Technologique
- **Runtime & Gestionnaire de paquets :** Bun
- **Frontend :** React 18, Vite, TailwindCSS
- **Backend / API :** Serveur HTTP Bun modulaire, Prisma ORM
- **Base de données :** PostgreSQL conteneurisée via Docker Compose
- **Architecture :** Monorepo scindé en `apps/` (`web`, `api`) et `packages/` (`database`, `shared`)
