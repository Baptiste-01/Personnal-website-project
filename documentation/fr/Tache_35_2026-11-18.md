## 🎯 Objectif
Permettre la mise en ligne complète, persistante et 100% gratuite (0 €) de l'ensemble de la plateforme **Smik Party** (Frontend React 18, Backend WebSockets Bun/Elysia et Base PostgreSQL Prisma) afin de rendre le jeu testable par des recruteurs ou pairs tout en conservant le dépôt de code source GitHub **strictement privé**.

---

## 📋 Plan d'action
1. **Adaptation de l'API (`apps/api`) pour le Cloud** :
   - Prise en charge dynamique des variables d'environnement `PORT` et `HOST` (requises par Render/Koyeb).
   - Configuration SSL automatique dans le client Prisma (`@prisma/adapter-pg`) pour les bases PostgreSQL cloud distantes (`neon.tech`, `supabase`).
2. **Conteneurisation Docker de production (`Dockerfile.api` & `render.yaml`)** :
   - Création d'un Dockerfile multi-étapes Bun optimisé pour l'API et la génération Prisma.
   - Création du manifeste `render.yaml` pour déploiement automatique sur le service gratuit de Render.com.
3. **Configuration du Frontend pour Vercel (`vercel.json`)** :
   - Mise en place des règles de réécriture SPA (`rewrites`) dans `apps/web/vercel.json` et à la racine pour éviter les erreurs 404 sur les routes côté client.
4. **Modèles d'environnement & Scripts de migration** :
   - Création de `.env.production.example` avec explications détaillées des variables nécessaires pour Render et Vercel.
   - Ajout des scripts `db:push:prod` et `db:seed:prod` dans [`package.json`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/package.json).
   - Sécurisation du fichier [`.gitignore`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/.gitignore) pour ignorer `.env.production` tout en versionnant les modèles d'exemple.
5. **Rédaction d'un guide complet pas à pas** :
   - Création de [`DEPLOYMENT_FREE_STACK.md`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/DEPLOYMENT_FREE_STACK.md) expliquant en 5 étapes la création de la base Neon, du service Render, du site Vercel et l'invitation des recruteurs.
