## Objectif
Mettre en place la structure monorepo initiale du projet basée sur l'outillage Bun, Docker Compose pour la persistance, ainsi qu'un premier prototype fonctionnel pour l'API et l'application Web.

## Plan d'action
1. Configurer la racine du monorepo (`package.json`, `bun.lock`, `.gitignore`).
2. Créer le conteneur PostgreSQL via `docker-compose.yml`.
3. Initialiser le package de base de données `packages/database` avec la configuration Prisma initiale.
4. Mettre en place le package partagé `packages/shared` pour les types et utilitaires communs.
5. Développer l'API minimale `apps/api` sous Bun HTTP.
6. Développer l'application web `apps/web` (React, Vite, TailwindCSS) avec page d'accueil d'accueil et présentation des modes de jeu.

## Réalisation
- Mise en œuvre de l'architecture modulaire complète en monorepo.
- Configuration des scripts TypeScript (`tsconfig.json`) et du linter (`eslint.config.js`).
- Déploiement d'une première interface React responsive mettant en avant le catalogue de jeux prévus (FlashGuess, BombParty, etc.).
- Initialisation du schéma de données Prisma et de l'environnement conteneurisé PostgreSQL.
