## Objectif

1. **Création du système de modèles (Templates de partie)** :
   - Permettre à chaque joueur disposant d'un compte de sauvegarder l'intégralité d'une configuration de jeu (catégories sélectionnées, difficultés par catégorie, tags, mode de manches fixes ou infinies, nombre de manches, temps par question, score maximum, limite de joueurs).
2. **Partage simplifié et universel entre joueurs** :
   - Génération d'un code de partage court et lisible (ex: `TMPL-7X2B`).
   - Génération d'un lien d'invitation direct (`/?template=TMPL-7X2B`) permettant à n'importe quel joueur (connecté ou invité) d'ouvrir le jeu avec les paramètres du modèle préchargés.
   - Système de catalogue public communautaire permettant d'explorer et de cloner les modèles populaires créés par d'autres joueurs.
3. **Intégration transparente dans le cycle de jeu** :
   - Dans le modal de création d'arène du **Lobby** : sélection en un clic d'un modèle personnel ou public, saisie d'un code de partage et bouton pour sauvegarder la configuration actuelle.
   - Dans le salon d'arène (**Arena**) : possibilité pour l'hôte d'appliquer un modèle ou de sauvegarder les réglages du salon, répercutés instantanément en temps réel sur les invités via WebSocket.
   - Dans la page **Profil** : nouvel onglet dédié permettant de visualiser, renommer, supprimer, changer la visibilité (public/privé) ou importer un modèle par code.

## Architecture & Réalisation

### 1. Base de données & Modèle Prisma ([`packages/database/prisma/schema.prisma`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/packages/database/prisma/schema.prisma))

- Ajout de l'entité `GameTemplate` :
  - `id` : identifiant unique cuid.
  - `name` & `description` : nom et description du modèle.
  - `shareCode` : code court unique indexé (ex: `TMPL-8F2B`).
  - `isPublic` : visibilité dans le catalogue public (booléen).
  - `usageCount` : compteur de parties jouées / popularité.
  - `settings` : configuration JSON complète (`GameSettings`).
  - `userId` & `user` : relation clé étrangère avec cascade vers le modèle `User`.
- Régénération du client Prisma via `bun run db:generate`.

### 2. API Backend ([`apps/api/routes/templates.ts`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/api/routes/templates.ts))

Création d'un routeur modulaire préfixé par `/templates` et monté dans [`apps/api/index.ts`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/api/index.ts) :
- `GET /templates/my` : récupération des modèles appartenant à l'utilisateur authentifié (via Bearer token).
- `GET /templates/public` : catalogue des modèles publics classés par popularité (`usageCount`).
- `GET /templates/code/:shareCode` : récupération d'un modèle par son code de partage avec incrémentation optionnelle du compteur d'utilisation (`?use=true`).
- `POST /templates` : création d'un modèle avec génération sécurisée d'un code alphanumérique unique `TMPL-XXXX`.
- `PUT /templates/:id` : mise à jour du nom, de la description, des réglages ou de la visibilité (contrôle de propriété ou privilèges administrateur).
- `DELETE /templates/:id` : suppression sécurisée d'un modèle.
- `POST /templates/clone/:shareCode` : duplication d'un modèle communautaire dans la bibliothèque personnelle du joueur.

### 8. Suppression de la perte de focus intempestive (cycle de 3 secondes)

- **Cause racine** :
  - Le `setInterval` du `Lobby` réactualisait discrètement la liste des arènes toutes les 3 secondes (`fetchArenas('silent')`), provoquant un re-render de `Lobby`.
  - La fonction de fermeture transmise à `CreateArenaModal` (`onClose`) était recréée à chaque cycle et figurait dans le tableau de dépendances d'un `useEffect` qui appelait `inputRef.current?.focus()`.
  - Conséquence : toutes les 3-4 secondes, le focus était arraché du champ de saisie du titre du template pour être remis sur l'input du nom d'arène.
- **Résolution ([`apps/web/src/pages/Lobby/index.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Lobby/index.tsx))** :
  - `inputRef.current?.focus()` est désormais exécuté **uniquement au montage initial** (`useEffect(..., [])`).
  - Utilisation d'une référence stable `onCloseRef` pour l'écouteur de la touche `Escape`.
  - Mise en pause du polling silencieux d'arènes en arrière-plan dès qu'un modal (`CreateArenaModal` ou `TemplateModal`) est ouvert.
  - Dans [`apps/web/src/components/TemplateModal/TemplateModal.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/components/TemplateModal/TemplateModal.tsx), ajout d'un autofocus dédié sur l'input de titre (`saveNameInputRef`) et protection contre toute réinitialisation de l'onglet pendant la saisie.

### 9. Calibrage des boutons et correction de l'écrasement du texte par les icônes SVG

- **Symptôme** :
  - Sur les cartes de modèles, les boutons « Appliquer » et « Partager », ainsi que les badges « Privé » et de code de partage affichaient des icônes SVG démesurées (40-60px), masquant le libellé textuel (« Ap... », « Pa...jer »).
- **Correctifs apportés ([`apps/web/src/components/TemplateModal/TemplateModal.css`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/components/TemplateModal/TemplateModal.css) & [`apps/web/src/pages/Profile/Profile.css`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Profile/Profile.css))** :
  - Définition d'un plafond strict de dimensions SVG à l'échelle du modal (`width: 15px; height: 15px; max-width: 15px; max-height: 15px; display: inline-block`).
  - Calibrage explicite pour chaque élément :
    - `.btn-tpl-apply svg` : 14×14px (avec `white-space: nowrap` pour préserver le mot « Appliquer »).
    - `.btn-tpl-action svg` : 13×13px (avec `white-space: nowrap` pour préserver « Partager »).
    - `.template-badge svg` : 12×12px (cadenas et globe).
    - `.template-item-code-badge svg` : 13×13px (icône de copie).
    - `.btn-tpl-danger svg` : 13×13px (corbeille).
  - Réplication des règles dans `Profile.css` pour une cohérence parfaite sur la page de profil.
