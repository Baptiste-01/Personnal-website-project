# Tâche 27 : Correction scripts Windows (AppLocker), gestion des privilèges administrateur (isAdmin) et suppression d'arènes

- **Date :** 2026-11-05
- **Auteur :** Antigravity & Baptiste-01
- **Statut :** Terminé

---

## Objectif

1. **Lancement de l'application sous Windows (`bun run dev` / `bun run online`)** :
   - Résoudre l'échec brutal des commandes de démarrage qui s'arrêtaient avec l'erreur :
     ```text
     bun: unknown error:
     error: script "dev" exited with code 1
     ```
   - Identifier et contourner les blocages causés par les stratégies de sécurité Windows sur les binaires compilés générés dans `node_modules/.bin/`.

2. **Transmission et synchronisation des privilèges administrateur (`isAdmin`)** :
   - Corriger l'absence du champ `isAdmin` dans les réponses des endpoints d'authentification (`/auth/register`, `/auth/login`, `/auth/me`), qui empêchait le profil utilisateur côté client de bénéficier des droits administrateur existant en base de données.

3. **Restriction de l'accès au panneau d'administration** :
   - Réserver l'affichage du bouton « 📊 Admin » dans la barre de navigation du Lobby aux seuls comptes connectés dotés du statut administrateur (`authUser?.isAdmin === true`).
   - Protéger la page `/admin` contre les accès directs en redirigeant les utilisateurs non autorisés.

4. **Suppression sécurisée des arènes par les administrateurs** :
   - Permettre aux administrateurs de supprimer les arènes obsolètes ou inutilisées directement depuis les cartes d'arènes du Lobby avec confirmation préalable.
   - Sécuriser l'endpoint backend `DELETE /arenas/:id` pour vérifier les privilèges de l'appelant via son jeton de session.

---

## Causes racines identifiées

1. **Blocage de sécurité Windows (AppLocker / Contrôle d'application)** :
   - Sous Windows, les binaires exécutables générés dans `node_modules/.bin/*.exe` (notamment `concurrently.exe` à la racine et `vite.exe` dans `apps/web`) sont interceptés et bloqués par la stratégie de sécurité Windows Defender Application Control / AppLocker :
     `Le programme «concurrently.exe» n’a pas pu s’exécuter: Une stratégie de contrôle d’application a bloqué ce fichier`.
   - Lorsque Bun tentait d'appeler ces shims `.exe` précompilés, le sous-processus était rejeté avec une erreur de permission Win32 opaque (`unknown error`).

2. **Omission du champ `isAdmin` dans les payloads Auth API** :
   - Le modèle Prisma `User` stockait bien `isAdmin: true` pour le compte `smikens`, mais les routes d'authentification ne l'incluaient pas dans l'objet `user` retourné au client.

## Réalisation

### 1. Contournement des shims `.exe` via Bun
- À la racine ([`package.json`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/package.json)) :
  Remplacement de l'appel barebone `concurrently` par l'exécution directe du runtime JavaScript `bun ./node_modules/concurrently/dist/bin/concurrently.js` pour les scripts `dev` et `online`.
- Côté frontend ([`apps/web/package.json`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/package.json)) :

  Exposition du champ `isAdmin: user.isAdmin` dans les routes `/auth/register`, `/auth/login` et `/auth/me`.
- [`apps/web/src/pages/Lobby/index.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Lobby/index.tsx) :
  - Interrogation automatique de `/auth/me` au montage si un jeton est présent pour synchroniser instantanément les droits dans `localStorage`.
  - Conditionnement de l'affichage du bouton Admin : `{isConnected && authUser?.isAdmin && <button ...>}`.
- [`apps/web/src/pages/Admin/index.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Admin/index.tsx) :
  Redirection automatique vers `/login` ou `/` pour les visiteurs non connectés ou non administrateurs.

### 3. Suppression des arènes pour les administrateurs
- [`apps/api/routes/arenas.ts`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/api/routes/arenas.ts) :
  Sécurisation de `DELETE /arenas/:id` avec validation du jeton de session administrateur (`session.user?.isAdmin`).
- [`apps/web/src/pages/Lobby/index.tsx`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Lobby/index.tsx) & [`Lobby.css`](file:///c:/Users/bapti/Desktop/Moi/Projet-Perso/Personnal-website-project/apps/web/src/pages/Lobby/Lobby.css) :

  - Gestion du clic avec `e.stopPropagation()` pour éviter d'entrer dans l'arène lors du clic sur la corbeille.
  - Boîte de dialogue de confirmation native `window.confirm` et mise à jour réactive de la liste d'arènes.
