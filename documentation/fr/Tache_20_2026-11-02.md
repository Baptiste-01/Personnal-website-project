# Tâche 20 : Correction de l'import Excel pour questions visuelles multiples & Règles AGENTS.md

- **Date :** 2026-11-02
- **Auteur :** Antigravity & Baptiste-01
- **Statut :** Terminé

---

## Objectif
1. **Résolution du bug d'écrasement des questions visuelles lors de l'import Excel** :
   - Dans le fichier d'importation `smik_party_questions_template.xlsx`, les questions visuelles (ex : les 195 pays de la catégorie « Drapeaux ») possèdent le même libellé de question (`text: "Quel est ce drapeau ?"`), mais se différencient par leur image (`imageUrl`) et leur réponse (`answer`).
   - Le système d'importation précédent effectuait une recherche par libellé brut (`where: { text: questionText }`) sans considération de catégorie ni d'image, écrasant ainsi la question précédente à chaque ligne et ne conservant qu'une unique question au final.
2. **Création du fichier `AGENTS.md`** :
   - Formaliser les règles et directives applicables aux agents IA intervenant sur le dépôt.
   - Établir l'obligation d'ajouter pour chaque tâche une documentation bilingue (FR et EN) dans le dossier `documentation/`.

---

## Plan d'action
1. **Backend API (`apps/api/routes/import.ts`)** :
   - Modifier la logique de déduplication/upsert pour distinguer les questions visuelles (par `category` + `imageUrl`, avec repli sur `category` + `text` + `answer`) des questions purement textuelles (par `category` + `text` avec vérification de l'absence d'image).
   - Inclure la mise à jour du champ `text` dans l'opération d'upsert pour propager d'éventuelles corrections textuelles.
   - Sécuriser le typage strict sur la lecture des feuilles et lignes Excel.
2. **Backend API (`apps/api/routes/questions.ts`)** :
   - Corriger l'avertissement de typage strict sur l'opération de shuffle générique.
3. **Formalisation des règles agent (`AGENTS.md`)** :
   - Rédiger le fichier racine `AGENTS.md` contenant la règle de documentation bilingue obligatoire, les interdictions strictes (git commit/push), et les consignes de frugalité.
4. **Mise à jour de la documentation** :
   - Créer `documentation/fr/Tache_20_2026-11-02.md` et `documentation/en/Task_20_2026-11-02.md`.
   - Mettre à jour les index `documentation/fr/README.md` et `documentation/en/README.md`.

---

## Réalisation
- **Déduplication robuste dans `import.ts`** :
  - Recherche ciblée pour les questions à image :
    ```typescript
    if (imageUrl) {
      existing = await prisma.question.findFirst({
        where: {
          category: { equals: category, mode: 'insensitive' },
          imageUrl,
        },
      })
      if (!existing) {
        existing = await prisma.question.findFirst({
          where: {
            category: { equals: category, mode: 'insensitive' },
            text: { equals: questionText, mode: 'insensitive' },
            answer: { equals: answer, mode: 'insensitive' },
          },
        })
      }
    }
    ```
  - Les 195 drapeaux ont désormais chacun leur propre enregistrement persistant en base sans s'écraser mutuellement.
- **Création de `AGENTS.md`** : référence permanente pour tous les agents IA définissant le workflow de documentation bilingue et les standards de code.
