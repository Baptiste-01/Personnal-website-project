# Tâche 25 : Import/Export CSV, Suppression de questions/catégories et Ordre strict des difficultés (Easy, Normal, Hard)

- **Date :** 2026-11-05
- **Auteur :** Antigravity & Baptiste-01
- **Statut :** Terminé

---

## Objectif

1. **Exportation des questions en CSV (`.csv`)** :
   - Permettre aux administrateurs de télécharger l'intégralité du catalogue de questions en format CSV standard RFC 4180.
   - Assurer la compatibilité avec Microsoft Excel et Google Sheets grâce à l'adjonction automatique du BOM UTF-8 (`\uFEFF`) pour préserver les caractères accentués français.
2. **Importation universelle de fichiers CSV** :
   - Supporter le téléversement direct de fichiers `.csv` dans la zone de dépôt ou par sélection de fichier.
   - Détecter automatiquement le délimiteur (virgule `,` ou point-virgule `;` fréquent sous les versions françaises d'Excel).
   - Supporter l'import multi-catégories via la colonne dédiée `catégorie` / `category`, ou l'attribution automatique à partir du nom du fichier pour les fichiers mono-catégorie.
   - Gérer correctement les champs multi-lignes et les guillemets échappés (`""`).
3. **Suppression de questions et de catégories en base de données** :
   - Offrir un moyen simple et sécurisé aux administrateurs de supprimer des questions individuelles directement depuis les cartes d'aperçu.
   - Permettre la suppression complète d'une catégorie et de toutes ses questions associées depuis le tableau de bord des statistiques, avec boîte de dialogue de confirmation native.
4. **Ordre strict d'affichage des difficultés** :
   - Garantir un ordre immuable des difficultés sur l'ensemble du site et dans le tableau de bord : **Easy**, **Normal**, **Hard**.
   - Uniformiser le tri des statistiques par catégorie (`Easy` -> `Normal` -> `Hard`), les filtres de cartes et le tri par défaut des questions récupérées du serveur.

---

## Plan d'action

1. **Backend API (`apps/api/routes/import.ts`)** :
   - Développer le parseur robuste `parseCsv` avec détection automatique du délimiteur (`,` vs `;`), gestion des guillemets imbriqués, multilignes et regroupement par catégorie.
   - Étendre `POST /admin/import` pour accepter l'extension `.csv` aux côtés de `.xlsx`, `.xls` et `.md`.
   - Étendre `GET /admin/export` avec le support `?format=csv` (colonnes normalisées : `catégorie`, `question`, `réponse`, `réponses_acceptées`, `difficulté`, `image_url`, `tag`), échappement RFC 4180 et préfixe BOM UTF-8.
   - Implémenter `DELETE /admin/questions/:id` pour supprimer une question par son identifiant unique.
   - Implémenter `DELETE /admin/categories/:category` pour supprimer en cascade toutes les questions d'une catégorie et l'enregistrement de catégorie associé.
   - Implémenter `GET /admin/questions` pour lister les questions de la base de données avec tri strict (par catégorie puis par niveau de difficulté ordonné `Easy` -> `Normal` -> `Hard`).
   - Normaliser l'ordre de tri de la répartition des difficultés dans `GET /admin/stats`.
2. **Interface Admin Frontend (`apps/web/src/pages/Admin/index.tsx`)** :
   - Mettre à jour `handleFile` et l'input de fichier pour autoriser `.csv`.
   - Étendre le gestionnaire `handleDownloadExport` avec le format `'csv'`.
   - Ajouter le bouton d'exportation CSV avec icône dédiée et style bleu.
   - Ajouter un bouton de suppression (`🗑️`) par catégorie dans la grille des statistiques avec confirmation (`window.confirm`).
   - Ajouter le bouton « 🔍 Gérer toutes les questions » pour charger les questions de la base de données dans la vue d'aperçu.
   - Ajouter un bouton de suppression (`🗑️`) sur chaque carte de question individuelle.
   - Ordonner strictement les compteurs de difficulté par catégorie et les boutons de filtrage sous la forme : `Easy`, `Normal`, `Hard`.
3. **Feuille de styles (`apps/web/src/pages/Admin/Admin.css`)** :
   - Déclarer la classe `.btn-export--csv` avec un dégradé bleu distinctif.
   - Déclarer les styles pour `.btn-delete-cat`, `.btn-manage-db`, `.stats-item-header`, et `.preview-card-delete-btn`.
4. **Validation technique** :
   - Vérifier la compilation frontend (`bun run build`) et le typage strict (`bun x tsc -p apps/api/tsconfig.json --noEmit`).

---

## Réalisation

- **Moteur d'importation et d'exportation CSV** :
  - La fonction `parseCsv` analyse et normalise les fichiers `.csv` quelle que soit l'origine (Excel français avec `;` ou Google Sheets / outils anglo-saxons avec `,`).
  - La route `/admin/export?format=csv` produit un fichier conforme RFC 4180 encodé en UTF-8 avec BOM, immédiatement lisible dans Excel sans corruption de caractères.
- **Gestion et suppression sécurisée** :
  - Suppression unitaire de question via `DELETE /admin/questions/:id` avec rafraîchissement réactif du state et des statistiques.
  - Suppression globale de catégorie via `DELETE /admin/categories/:category` supprimant les questions orphelines et nettoyant la table des catégories.
- **Ordre strict des difficultés (Easy, Normal, Hard)** :
  - Mappage déterministe des niveaux (`facile/easy` = 1, `moyen/normal/medium` = 2, `difficile/hard` = 3) appliqué à l'API (`stats`, listing) et au front-end (badging, filtres, compteurs).
